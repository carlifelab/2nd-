# CarLifeLab

中古車の査定・売却、リセールバリュー、車検、維持費、乗り換え判断に役立つ情報を提供する静的Webサイトです。

## 公開サイト

https://carlifelab.github.io/2nd-/

## 主なコンテンツ

- 車査定・車売却の総合ガイド
- ディーラー下取りと買取店の比較
- 売却前の準備、車検前の売却、ローン残債がある場合の売却
- 維持費・乗り換えコスト計算機
- 国内人気車ランキング
- 中古車輸出需要ランキング
- 中古車購入前チェックリスト
- プライバシーポリシー・免責事項

## サイト構成・運用

- HTML/CSS/JavaScriptによる静的サイト
- GitHub Pagesで公開
- 検索エンジン向けサイトマップ：`sitemap.xml`
- クロール設定：`robots.txt`（`sitemap.xml`を指定）

## 更新時の注意

- ページを追加・削除した場合は、`sitemap.xml`も更新する
- 各ページのtitle、description、canonical、内部リンクを確認する
- ランキングや相場など変動する情報は、出典と基準日を明記する
- アフィリエイトリンクを掲載する場合は、広告であることが分かる表示と各サービスの規約を確認する

## 収益化・改善の方向性

検索意図に合った記事と無料計算ツールを入口にし、車の売却検討者へ査定サービスの比較・申込み導線を提供します。検索流入、記事閲覧、リンククリック、成果を確認しながら改善します。
